    What's a skill?

    A skill is a focused, model-agnostic instruction set the AI loads on demand: when to activate, what to do, references, examples, and (optionally) runnable code. Skills are version-controlled, reviewable in PRs, and portable across IDEs. Every skill in this pack maps to a real production incident — not theoretical advice.
